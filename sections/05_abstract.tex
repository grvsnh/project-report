  \FrontLine{abstract-heading}{\textbf{ABSTRACT}}

  \FrontParagraph{abstract-body}{
    VeerDrishti is an Android-based computer-vision prototype for real-time visual situational
    awareness. It captures camera frames and applies on-device YOLO26 Nano task variants through
    Flutter YOLOView, with CameraX handling capture and rotation. The prototype displays detection
    boxes, segmentation masks, pose keypoints, configurable confidence and IoU thresholds, and
    runtime indicators in portrait and landscape views. The available demonstrations verify the
    capture-to-display pipeline and task-specific visual outputs. Displayed readings range from
    11.9 to 21.3 FPS across the supplied screenshots; these observations are not a sustained
    accuracy or latency benchmark. Controlled evaluation on annotated, combat-relevant data
    remains future work.
  }
